# infra-monitoring-project

Проект мониторинга API-сервиса: Bash-скрипты, Docker Compose, CI/CD.

## Структура проекта

- `check_api.sh` — проверка доступности API
- `analyze_logs.sh` — анализ access.log
- `docker-compose.yml` — стек api + nginx
- `.github/workflows/ci.yml` — CI пайплайн
